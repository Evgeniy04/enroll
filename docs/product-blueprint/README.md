# Product Blueprint — «Впору» (рабочее название)

Комплект проектной документации будущего web-продукта, выросшего из прототипа `enroll` (Expo/React Native).
Документы описывают **целевое состояние** продукта и решения, которые к нему ведут. Код продукта в рамках этой задачи не пишется и не изменяется.

> Название «Впору» — **предварительный выбор**. Оно не прошло проверку по базам Роспатента/ФИПС и требует утверждения владельцем и проверки патентным поверенным (см. [12](12-naming-legal-review.md)). Во всех документах название вынесено в один токен бренда, его замена не затрагивает архитектуру.

Визуальная часть (направления бренда, токены, ключевые экраны, карта сценариев) — в Design-артефакте: https://claude.ai/artifact/Lgb2U2SQCvMjk2h9STTpcP

## Маркировка утверждений

| Метка | Значение |
|---|---|
| **[Факт]** | Подтверждено кодом, видео, диаграммой или источником (указан) |
| **[Вывод]** | Следует из нескольких фактов |
| **[Гипотеза]** | Правдоподобно, требует проверки (указан способ) |
| **[Решение]** | Принятое проектное решение (см. [22](22-decision-log.md)) |
| **[Неизвестно]** | Нет данных; вынесено в [21](21-open-questions.md) |
