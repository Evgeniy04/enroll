Формат каждого вопроса: варианты, последствия, временное решение (принято в документах до ответа).

| ID | Вопрос | Варианты | Последствия | Временное решение | Блокирует |

## 3. Реестр рисков

| ID | Риск | Вероятность | Влияние | Митигация | Владелец |
|---|---|---|---|---|---|
| R-01 | Название недоступно юридически | С | В | Шорт-лист из 3 имён, изоляция бренда (D-05) | Владелец |
| R-02 | Низкая активация специалистов | С | В | Онбординг ≤ 15 мин, шаблоны-пресеты, пилот с интервью | Продукт |
| R-03 | Письма попадают в спам | С | В | SPF, DKIM, DMARC, прогрев, отдельный домен, мониторинг bounce; Telegram | Разработка |
| R-04 | Молодость TanStack Start | С | С | Фреймворк-независимый домен и API, запасной React Router 8 | Разработка |
| R-05 | Ошибки расчёта окон (часовые пояса) | Н | В | Property-based тесты, ограничение БД как последний рубеж | Разработка |
| R-06 | Правовые претензии по ПД | Н | В | Юр. проверка документов, минимизация, локализация | Владелец |
| R-07 | Спам-записи и блокировка расписания | С | С | Hold через email, лимиты, капча | Разработка |
| R-08 | Недоступность GitHub или зарубежных инструментов | Н | С | Переносимый CI, зеркала зависимостей | Разработка |
| R-09 | Конкуренты копируют «шаблоны дня» | С | Н | Скорость, фокус на соло-специалисте, качество UX | Продукт |
| R-10 | Специалисты хотят хранить сведения о здоровье клиентов | С | С | Не собирать в MVP; отдельная правовая оценка (CLI-02) | Владелец |
