# 09. Дизайн-спецификация

Визуальная концепция рекомендуемого направления бренда «Аккурат» ([10](10-brand-strategy.md)). Наглядно — артборды «Аккурат — токены и компоненты», «Публичная страница записи», «Кабинет: календарь», «Кабинет: расписание» в Design-артефакте.

**Характер:** спокойный, точный, тёплый. Тёплый светлый фон, глубокий сине-зелёный акцент, крупные цифры времени.

**[Решение]** Нейтральная палитра shadcn из прототипа не переносится: она не несёт идентичности. Структура токенов (семантические роли и пары foreground) переносится.

## 1. Принципы визуального языка

1. **Время — герой.** Цифры времени крупнее окружающего текста, моноширинные цифры (`tabular-nums`), в акцентном шрифте.
2. **Капсула-окно.** Мотив логотипа — скруглённое «окно» с отметкой-галочкой — повторяется в форме чипов окон (радиус 10) и в индикаторе выбора (галочка у выбранного окна).
3. **Мало цвета, много смысла.** Акцент — только для главного действия и выбранного состояния. Статусы — пастельные заливки с тёмным текстом.
4. **Без декоративных градиентов и эмодзи** в интерфейсе (градиентные иконки прототипа не переносятся).

## 3. Типографика

| Роль | Шрифт | Размер / межстрочный | Начертание |
|---|---|---|---|
| Display | Onest | 40 / 44 (мобильный 32 / 36) | 700, −0.02em |
| H1 | Onest | 28 / 34 | 600–700 |
| H2 | Onest | 20 / 26 | 600 |
| Body | Golos Text | 16 / 24 | 400 |
| Body strong | Golos Text | 16 / 24 | 600 |
| Small | Golos Text | 14 / 20 | 400 |
| Caption | Golos Text | 13 / 18 | 400–600 |
| Time | Onest | 16–20 | 600, `tabular-nums` |

**Обоснование:**
- Onest и Golos Text — открытые шрифты (SIL OFL 1.1) с полноценной кириллицей, спроектированы в первую очередь для русского языка;
- Golos хорошо читается в интерфейсах на малых кеглях;
- Onest даёт характер заголовкам и цифрам;
- лицензия разрешает встраивание и коммерческое использование ([17](17-security-and-compliance.md) §8).

Загрузка: self-host WOFF2 (не Google Fonts в production — чтобы не передавать IP посетителей третьей стороне), `font-display: swap`, сабсеты `cyrillic` и `latin`, preload двух начертаний.

Минимальный размер текста интерфейса — 13 px. Основной текст — 16 px (исключает автозум iOS в полях).

## 4. Отступы, размеры, радиусы, тени

- **Шкала отступов (4-pt):** 4, 8, 12, 16, 24, 32, 48, 64.
- **Радиусы:** `sm 6` (бейджи внутри), `md 10` (кнопки, поля, чипы), `lg 16` (карточки, панели), `pill 999`.
- **Высоты:**
  - кнопки 44 (основная), 36 (компактная в тулбаре), 52 (закреплённая нижняя на телефоне);
  - поля 44;
  - строки списков ≥ 48.
- **Тени:** почти не используются. Панели отделяются границей `line`; плавающие элементы (тост, меню) — `0 8px 24px rgba(23,32,29,0.16)`.

## 5. Сетка и брейкпоинты

| Брейкпоинт | Ширина | Сетка | Поля |
|---|---|---|---|
| `xs` | < 640 | 4 колонки | 16 |
| `sm` | 640–1023 | 8 колонок | 24 |
| `md` | 1024–1279 | 12 колонок, gutter 24 | 24 |
| `lg` | ≥ 1280 | 12 колонок, контент ≤ 1200 (публичная) / fluid (кабинет) | 32 |

Боковая навигация кабинета — 240 px с `md`. Панель деталей — 340–480 px. Ширина текстовых блоков ≤ 68 ch.

## 6. Компоненты (ядро дизайн-системы)

| Компонент | Варианты и состояния | Примечания доступности |
|---|---|---|
| Button | primary, secondary (outline), ghost, danger; размеры 44/36/52; состояния default, hover, active, focus-visible, disabled, loading (спиннер + `aria-busy`) | Нативный `<button>`; иконка-только → `aria-label` |
| IconButton | 44×44 | `aria-label` обязателен |
| TextField, Textarea | default, focus, invalid, disabled; helper, error | Подпись `<label>`, `aria-describedby` |
| NumberStepper | поле, −/+, пресеты-чипы | `role="group"`, подпись |
| TimeField | `HH:MM` с маской и списком | — |
| Select / Combobox | одиночный выбор, поиск (клиенты) | Паттерн ARIA combobox |
| Chip / Toggle chip | обычный, выбран (`aria-pressed`), недоступен | — |
| **SlotChip** (окно) | свободно, выбрано, наведение, занято (пунктир, зачёркнуто, `disabled`) | Цвет не единственный признак |
| **DayPill** (лента дней) | обычный, выбран, выходной, сегодня (обводка `brand-warm`) | `aria-label` «15 октября, четверг, свободно 5» |
| **MonthGrid** (расписание) | ячейка: шаблон (заливка и код), выходной (пунктир), прошедший (opacity 0.45), сегодня, выделение диапазона, предпросмотр (штриховка) | ARIA grid, `aria-selected` |
| **TemplateTimeline** | блоки, ошибка пересечения | Текстовый список блоков рядом с графикой |
| **CalendarWeek / Day** | запись по статусам, рабочий фон, «сейчас» (линия) | Каждая запись — кнопка с полным `aria-label` |
| StatusBadge | confirmed, pending, completed, cancelled, no_show | Иконка и текст |
| Drawer (боковая панель) | справа, 480 px; на телефоне — страница | Фокус-ловушка, `Esc` |
| Dialog | подтверждение, короткая форма | `role="dialog"`, `aria-modal` |
| Toast | success (+ «Вернуть»), error (+ «Повторить») | `role="status"` / `alert` |
| Banner | info, attention, danger | — |
| Skeleton | для списков, сетки | `aria-busy` на контейнере |
| EmptyState | иллюстрация-пиктограмма, текст, действие | — |
| Avatar | фото / инициалы на `accent-soft` | `alt` — имя |

## 7. Иконки и графика

- Иконки — Lucide (ISC), линия 2 px, размер 20/24, цвет `currentColor`. Lucide уже используется в прототипе.
- Иллюстраций нет. Пустые состояния — крупная пиктограмма в капсуле и текст.
- Логотип — знак «окно с галочкой» и словесный знак «аккурат» строчными буквами, только кириллицей (Onest Bold, трекинг −0.02em). Охранное поле — высота знака × 0,5.

## 8. Движение

Длительности 120 мс (hover), 180 мс (панели, тосты), easing `cubic-bezier(0.2, 0, 0, 1)`. При `prefers-reduced-motion: reduce` — без перемещений, только смена прозрачности.

## 9. Адаптивные правила (конкретно)

1. Публичная запись `< 640`: сводка выбора и «Продолжить» закреплены внизу (высота 52 + отступы). Контент получает `padding-bottom`, чтобы не перекрываться.
2. Лента дней прокручивается горизонтально с кнопками ‹ › (не только свайп).
3. Окна — сетка `repeat(auto-fill, minmax(96px, 1fr))` (3 колонки на 360 px).
4. Неделя календаря на `< 1024` — горизонтальная прокрутка внутри области с закреплённой колонкой часов. По умолчанию открывается вид «День».
5. Месячная сетка `< 640` — ячейки 44×56 с кодом шаблона без подписи числа записей; детали дня — по нажатию (bottom sheet).
6. Таблицы клиентов `< 640` превращаются в карточки.

## 10. Критерии проверки дизайна

- Все токены проходят автоматический контраст-тест (пары «текст / фон» из таблиц §2).
- Visual regression (Playwright screenshots) для компонентов в обеих темах и на 3 брейкпоинтах.
- Нет «голых» hex в коде компонентов — только токены (lint-правило).
