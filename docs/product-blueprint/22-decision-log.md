# 22. Журнал решений

Статусы:
- **Принято** — принято в blueprint;
- **Предварительно** — требует подтверждения владельцем;
- **Пересмотреть при** — указан триггер пересмотра.

| ID | Решение | Альтернативы | Обоснование | Статус | Документ |
|---|---|---|---|---|---|
| D-01 | Позиционирование: личная страница записи для **соло-специалиста** | Салонная CRM; маркетплейс | Подтверждено моками и логикой прототипа; рынок салонов занят | Предварительно (Q-01) | 02 |
| D-02 | **Web-first** адаптивный продукт; Expo-приложение не развивается | Продолжить React Native; универсальный Expo Web | Требование ТЗ; клиентам не нужна установка; один код | Принято | 00, 14 |
| D-03 | **Ссылка специалиста вместо «Контактов»** и поиска по username | Каталог; заявки в контакты | Клиенту неоткуда знать username; ссылка — естественный канал (соцсети) | Принято | 01 §10, 07 |
| D-04 | **Гостевая запись с кодом из письма**, аккаунт клиента опционален | Обязательная регистрация; запись без подтверждения | Конверсия (H-1) и защита от спама; подтверждение владения email | Принято, проверить H-1 | 04 BKG-01 |
| D-05 | Название изолировано в токенах и ассетах, slug без бренда | Название «вшито» в код и URL | Название не утверждено юридически | Принято | 10 §7 |
| D-06 | Рекомендованное название **«Впору»**, альтернативы «Сверим», «Авра» | «Окошко», «Аврамов. Запись», англ. варианты | Взвешенная оценка 4,15; кириллица соответствует 168-ФЗ | **Предварительно** (U-01) | 11, 12 |
| D-07 | Переиспользовать из прототипа: Zod-схемы, конфиг Better Auth, Drizzle-хелперы, env-валидацию, React Email | Переписать всё | Работающий и проверенный код | Принято | 14 §2 |
| D-08 | Фреймворк **TanStack Start** (запасной — React Router 8) | Next.js 16; SPA + API | Типизированный URL-state, TanStack Query, переносимость | Принято; пересмотреть при 2 блокирующих дефектах за квартал | 13 §2 |
| D-09 | **REST `/api/v1` на Hono** внутри процесса Start | Server functions; tRPC; GraphQL; отдельный сервис | Стабильный контракт для будущих клиентов, опыт с Hono | Принято | 13 §3 |
| D-10 | **PostgreSQL** | MySQL; SQLite; MongoDB | Exclusion constraint для запрета пересечений | Принято | 13 §4 |
| D-11 | **Drizzle**, только SQL-миграции (без `db:push`) | Prisma; Kysely | Уже в прототипе, SQL-близость | Принято | 13 §4 |
| D-12 | Рабочий день хранит **снимок блоков** шаблона | Ссылка на живой шаблон | Изменение шаблона не меняет неожиданно опубликованные окна; явное «обновить будущие дни» | Принято | 15 |
| D-13 | **Better Auth** с email OTP, `SameSite=Lax` | Auth.js; своя реализация | Работает в прототипе; безопаснее, чем `none` | Принято | 13 §5, 17 |
| D-14 | Row Level Security — в Next; в MVP проверки владения в use cases и тесты IDOR | RLS сразу | Простота MVP; RLS как второй рубеж позже | Принято | 14 §6 |
| D-15 | Очередь **pg-boss** в Postgres | BullMQ + Redis; cron | Без новой инфраструктуры, транзакционная постановка | Принято; пересмотреть при > 50 задач/с | 13 §7 |
| D-16 | Хостинг **Yandex Cloud** (запасной Selectel, бюджетный Timeweb) | Зарубежные PaaS | 152-ФЗ (локализация), управляемые сервисы, почта в РФ | Предварительно (Q-07) | 19 §5 |
| D-17 | UI-примитивы **React Aria Components** + Tailwind v4 | Radix + shadcn; Mantine | Доступные дата- и время-компоненты с часовыми поясами | Принято | 13 §6 |
| D-18 | В MVP только **email-уведомления** | Telegram и SMS сразу | Объём MVP; стоимость SMS | Предварительно (Q-06, H-3) | 05 |
| D-19 | **Нет переписки** клиента и специалиста в продукте | Чат | Объём; риски 149-ФЗ (ОРИ) | Принято | 17 §6 |
| D-20 | **Hold окна на 10 минут** на время подтверждения кода | Без hold; дольше | Честный опыт без «украденного» окна; ограниченный риск блокировки | Принято | 04 BKG-01 |
| D-21 | Автоматический переход в `completed` через 1 ч после конца | Ручная отметка | Меньше ручной работы; `no_show` — ручная отметка | Принято | 15 §4 |
| D-22 | Формат slug `[a-z0-9-]{3,32}` и список зарезервированных | Произвольные строки | Безопасные короткие URL, нет коллизий с маршрутами | Принято | 07 |
| D-23 | Шрифты **Onest + Golos Text**, self-hosted | Inter или Roboto; Google Fonts CDN | Кириллица, характер, OFL; без передачи IP третьим лицам | Принято | 09 §3 |
| D-24 | Палитра: сине-зелёный акцент на тёплом фоне | Нейтральная shadcn из прототипа | Идентичность, контраст AA с запасом | Предварительно (вместе с D-06) | 09 §2 |
| D-25 | Ошибки — **self-hosted GlitchTip** в РФ; не Sentry SaaS | Sentry SaaS | Трансграничная передача ПД | Принято | 14 §10 |
| D-26 | Хранение времени в UTC, расчёт в IANA-зоне специалиста | Локальное время в БД | Корректность при разных поясах | Принято | 15 |
| D-27 | Деньги в копейках (`integer`), цена опциональна | `numeric`; без цены | Точность; цены нет в прототипе, но она нужна клиенту (N-10) | Принято | 15 |
| D-28 | Не собирать специальные категории ПД (здоровье) в MVP | Заметки о клиенте | ст. 10 152-ФЗ | Принято; пересмотреть с юристом (R-10) | 17 §5.3 |
| D-29 | **Один профиль специалиста на пользователя** | Несколько видов деятельности (схема прототипа) | Простота; нет подтверждённой потребности | Принято (Q-10) | 15 |
| D-30 | В интерфейсе «окно» и «время» вместо «слот» | «Слот» | Язык аудитории ([10](10-brand-strategy.md) §3) | Принято | 08, 10 |
