# Приложение B. Глоссарий

| Термин | Определение | В прототипе |
|---|---|---|
| **Специалист** | Пользователь с профилем, принимающий записи на свои услуги | «Специалист», «Контакт» |
| **Клиент** | Человек, записывающийся к специалисту; может не иметь аккаунта (гость) | — |
| **Профиль / страница** | Публичная страница специалиста `/{slug}` | ProfileDetails |
| **Slug (адрес ссылки)** | Уникальная часть URL: `anna-nails` | username |
| **Услуга** | То, на что записываются: название, длительность, перерыв после, цена | Service |
| **Длительность** | Время оказания услуги, мин | duration |
| **Перерыв после** | Время подготовки к следующему клиенту после сеанса; не видно клиенту как часть записи | breakAfter |
| **Шаблон дня** | Именованный набор блоков, описывающий типичный рабочий день («Стандартный», «Короткий», «Вечерняя смена») | Template, «тип рабочего дня» |
| **Блок** | Часть шаблона: услуга × время начала × количество сеансов подряд | ScheduleSlot |
| **Сеанс** | Один повтор блока: `[начало, начало + длительность)`, за ним перерыв | — |
| **Рабочий день** | Дата с назначенным шаблоном (снимок блоков); отсутствие — выходной | DayCard (без хранения) |
| **Кисть** | Режим назначения шаблона на дни кликом в месячной сетке | — |
| **Правило заполнения** | Массовое назначение шаблона: период, дни недели, смены | «Инструменты заполнения»: Периоды, Недели, Смены |
| **Горизонт записи** | Как далеко вперёд клиенты могут записываться | «Ограничение записи» |
| **Минимальное время до записи** | Насколько заранее нужно записаться | — |
| **Срок отмены** | До какого момента клиент может сам отменить или перенести | — |
| **Окно** | Вычисленное свободное время для записи на конкретную услугу | «Доступное время» |
| **Hold** | Временное (10 мин) резервирование окна на время подтверждения кода | — |
| **Запись** | Бронь клиента на окно; имеет статус | Event |
| **Ручная запись** | Запись, созданная специалистом (по звонку) | — |
| **Токен управления** | Секретная ссылка из письма для переноса и отмены без входа | — |
| **Клиентский контакт** | Карточка клиента в списке конкретного специалиста | — |
| **ПД** | Персональные данные (152-ФЗ) | — |
| **Оператор / обработчик ПД** | Лицо, определяющее цели обработки / лицо, обрабатывающее по поручению оператора | — |
| **MVP / Next / Future / HYP** | Приоритеты требований ([04](04-requirements.md)) | — |
